# Әхлак курсы

Дүрт курс һәм 97 интерактив дәрес. Укучы нәтиҗәләре автоматик рәвештә шәхси Supabase журналына җибәрелә.

- Укучы сайты: `index.html`
- Укытучы журналы: `teacher.html`
- Нәтиҗәләр таблицасы: `akhlaq_quiz_attempts`
- Edge Function: `submit-akhlaq-quiz`

Журналга керү өчен Supabase функциясендәге `TEACHER_PIN` сере кулланыла.
